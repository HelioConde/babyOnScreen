# Sprites gerados — Baby On Screen

Origem: pacote de 10 folhas de sprites preparado em 10/10/2026. Cada categoria possui recortes automáticos e, quando presentes, as folhas originais. Consulte `manifest.json` para coordenadas e metadados.

**Importante:** os recortes são preliminares. Conferir transparência, bordas, alinhamento, pivô, direção e consistência dos frames antes de usar como animações definitivas.

Para importar o ZIP preparado:

```bash
python tools/import_sprite_pack.py baby-on-screen-sprites-preparados.zip
```

A importação mantém as pastas banho, fralda, alimentacao, sono, crescimento, quarto, casa, quintal, escola e npcs.
