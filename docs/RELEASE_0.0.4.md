# Baby On Screen 0.0.4 — liberdade para mover no PC

Esta versão melhora a experiência de overlay e os computadores com dois ou mais monitores.

## Novidades

- **Arraste a bebê entre monitores**, inclusive telas que ficam à esquerda, acima ou abaixo da principal.
- **Mova o painel de cuidados** segurando o cabeçalho ou a alça ⠿. Também é possível mover pelo teclado usando as setas enquanto a alça está em foco.
- **Escolha o monitor** dentro do painel para reposicionar bebê e controles automaticamente.
- **Botão Minha amiguinha sempre acessível** no monitor atual da personagem.
- As posições são memorizadas, sem interferir nos cuidados, missões ou progresso salvo.
- Melhor adaptação a conexões e desconexões de monitores, preservando a transparência do overlay.
- Tutorial de boas-vindas atualizado para explicar os novos controles.

## Downloads

- **Setup:** `Baby-On-Screen-Setup-0.0.4-x64.exe` — instala e recebe as próximas atualizações automaticamente.
- **Portable:** `Baby-On-Screen-Portable-0.0.4-x64.exe` — não precisa de instalação; atualiza manualmente.
- Os links permanentes `Baby-On-Screen-Setup-x64.exe` e `Baby-On-Screen-Portable-x64.exe` continuam apontando à versão mais recente.

## Segurança

A partir da versão 0.0.3, os usuários do Setup podem receber esta atualização pelo atualizador dentro do jogo. Os binários **ainda não possuem assinatura digital**, portanto o Windows SmartScreen poderá continuar avisando “Fornecedor desconhecido”. Assinatura confiável e testes de reputação são uma etapa futura; não desative o SmartScreen.

## Testes recomendados

Mover bebê e caixa entre monitores com posições e DPI diferentes; selecionar o monitor; desconectar e reconectar uma tela; verificar passagem de cliques nos programas em segundo plano; fechar e reabrir pela bandeja do Windows; confirmar salvamento antes de atualizar.
