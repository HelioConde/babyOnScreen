# Baby On Screen 0.0.11 — O nome da sua bebê é para sempre 💕

## Primeira abertura

O primeiro passo apresenta uma tela no mesmo visual delicado do HUD, com a animação real da personagem: **Como vai se chamar sua bebê?**

Digite um nome com até 20 caracteres e clique em **Confirmar nome 💕**. A escolha não pode ser pulada nem fechada sem nomear a bebê. Escrever no campo não salva automaticamente: você pode revisar o nome antes de confirmar.

## Quem já joga

- Se sua bebê **já tem nome salvo**, ele será mantido e você não precisará escolher de novo.
- Se você já tem progresso, mas **não escolheu nome**, o jogo abre **somente a tela de nomeação** ao iniciar, mesmo que o tutorial antigo já tenha sido concluído.
- Cuidados, nível, habilidades, missões, tempo de vida e preferências continuam preservados.

## Nome definitivo

Depois de confirmar, o campo das Preferências é apenas para leitura. Não é possível renomear ao abrir novamente o guia nem substituí-lo ao importar outro progresso. O Windows mantém uma referência local do nome definitivo separada dos dados de jogo.

Isso é uma regra da experiência do jogo, e não um sistema antiviolação: arquivos locais podem ser modificados manualmente fora do aplicativo.

## Downloads e atualização

O Setup continua recebendo versões oficiais pelo atualizador automático do GitHub: **Atualizações → Verificar agora → Reiniciar e atualizar**. A Portable permite consultar e baixar novas versões.

Os links fixos de Setup e Portable permanecem no README e a release inclui o manifesto `latest.yml`.
