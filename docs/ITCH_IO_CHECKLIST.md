# Checklist de lançamento — Baby On Screen na itch.io

## Preparação técnica
- [x] Downloads Setup/Portable e links fixos de release no GitHub.
- [x] Atualização automática para a edição Setup, com manifesto `latest.yml`.
- [x] Tutorial inicial, nome da personagem e salvamento/exportação.
- [x] Interface prioritária para cuidados e botão de fechar acessível ao rolar (0.0.8, sujeito aos testes do build).
- [ ] Teste manual da versão mais recente em Windows 10 e 11 (100% e 125% de DPI).
- [ ] Teste real com dois monitores, YouTube ao fundo, painel rolando e atualização 0.0.7 → 0.0.8.
- [ ] Inspecionar executáveis finais e checar antivírus/SmartScreen (não contornar avisos).
- [ ] Considerar assinatura digital Authenticode para distribuição ampla.

## Direitos e segurança
- [ ] Conferir licenças e autorização comercial de **todos** os sprites, imagens, efeitos, músicas, fontes e packs importados; atribuir créditos quando exigido.
- [ ] Definir licença adequada para o código, assets próprios e assets de terceiros separadamente.
- [ ] Garantir que nenhuma chave privada/token seja enviada nos arquivos de distribuição.
- [ ] Publicar política de privacidade simples: saves locais, contato e uso eventual de acesso ao GitHub para atualizações.
- [ ] Incluir contato para suporte e denúncias.

## Loja e apoio voluntário
- [ ] Criar/verificar conta de criador na itch.io; configurar nome público e perfil.
- [ ] Configurar método de recebimento e validar requisitos do país, impostos e taxas.
- [ ] Configurar jogo grátis com contribuições opcionais; não prometer recompensas não implementadas.
- [ ] Publicar descrição, etiquetas, capa e capturas; distinguir Setup e Portable.
- [ ] Testar download público, instalação e atualização do próprio jogo.
- [ ] Somente após a página ser publicada, incluir seu URL real no README e no botão de apoio do aplicativo (nunca adivinhar o endereço).
- [ ] Comunicar lançamento aos primeiros jogadores e recolher feedback de desempenho, conforto de cuidados e acessibilidade.

## Objetivo
Lançamento gratuito e confiável. Apoios voluntários financiam trabalho futuro sem pressionar o jogador e sem travar recursos básicos.
