# Baby On Screen — texto da página itch.io (rascunho)

## Título
Baby On Screen — Sua amiguinha na área de trabalho

## Frase curta
Adote uma bebê virtual que brinca, cresce e faz companhia enquanto você trabalha, joga ou assiste a vídeos no PC.

## Descrição sugerida para a página (PT-BR)
**Uma pequena companheira, sempre por perto!** 💕

No Baby On Screen, uma bebê virtual passeia pela área de trabalho. Você pode arrastá-la, dar carinho, escolher seu nome e acompanhar seu crescimento. Quando ela precisar de atenção, abra a caixinha de cuidados: mamadeira, fralda, berço, brinquedos, cartinhas e desenhos.

O ritmo foi pensado para quem usa o computador por longos períodos. O jogo possui períodos de madrugada, manhã, tarde e noite, progresso automático, lembranças, missões e fases de crescimento. A versão instalada pelo Setup recebe novas versões pelo próprio jogo.

### Recursos
- Personagem pixel art animada em overlay transparente sobre a área de trabalho.
- Quatro fases, pequenas atividades e lembranças colecionáveis.
- Ações prioritárias no topo do painel, com intervalos moderados.
- Seleção de monitor e painel móvel no Windows.
- Salvamento local e backup JSON, sem exigir conta.
- Idioma: português brasileiro.

### Downloads
- **Setup (recomendado):** instala no Windows x64 e suporta atualização automática.
- **Portable:** executável independente; novas versões devem ser baixadas manualmente.
- [Versão Web gratuita](https://helioconde.github.io/babyOnScreen/) para experimentar.

### Apoie o desenvolvimento
**O jogo é gratuito.** Se você gostou e deseja ajudar a criar novas fases, roupas, ambientes e, futuramente, escola e interação com amigos, pode contribuir com um valor voluntário. Apoiar não concede vantagens exclusivas nem é requisito para jogar.

### Avisos
O instalador Windows ainda não possui assinatura digital, por isso o SmartScreen pode exibir alerta de fornecedor desconhecido. Baixe apenas de canais oficiais; não desative as proteções do sistema.

O multiplayer e os amigos online são ideias futuras e ainda **não estão disponíveis**. Os jogos Web e Windows compartilham regras, mas não sincronizam progresso automaticamente pela nuvem.
