# Baby On Screen 0.0.12 — cuidados mais rápidos no PC

- Mamadeira, fralda e berço: **7min30s**, em vez de 12min30s.
- Todas as outras ações e a escola: **30% do intervalo original**.
- A versão Web mantém os tempos anteriores, inclusive 25 minutos nos cuidados essenciais.
- Os cooldowns ainda ativos de instalações anteriores são encurtados uma única vez, sem apagar progresso nem nome.
- Atualização automática disponível para quem usa o Setup. A Portable pode ser obtida pela página Releases.

Testes automatizados verificam cálculo do tempo, diferença entre Web/PC e migração única dos dados.
