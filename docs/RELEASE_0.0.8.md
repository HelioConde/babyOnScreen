# Baby On Screen 0.0.8 — cuidados prioritários e painel mais simples

## Ajustes no Windows
- Tempos de espera entre ações reduzidos pela metade **somente no PC**. Alimentação, fralda e berço: **12 minutos e 30 segundos**; outras atividades, remédio e escola também diminuíram 50%.
- Cuidados principais agora aparecem antes das estatísticas no HUD, em ordem **Mamadeira → Fralda → Berço**.
- Cabeçalho acompanha a rolagem e o botão **X** permanece acessível mesmo com as seções expandidas.
- Removidos controles de teste de velocidade, pausa e recomeçar para evitar configurações acidentais.
- Mantidos som, nome, exportação/importação, salvamento automático e verificação de atualizações.
- Tempos pendentes de versões antigas são convertidos uma única vez no PC, sem apagar o progresso.

## Distribuição
Textos de apresentação e checklist de lançamento para a itch.io foram adicionados em `docs/ITCH_IO_STORE.md` e `docs/ITCH_IO_CHECKLIST.md`. Nenhuma página de pagamento foi publicada automaticamente.

A edição Web segue com os intervalos originais de 25 minutos para cuidados essenciais. O instalador continua não assinado e pode mostrar SmartScreen; verifique a origem do download.
